# الخط العربي المطلوب لتوليد PDF

ضع هنا ملف خط TTF يدعم الحروف العربية باسم `arabic.ttf` قبل استعمال ميزة
"إنشاء البرمجة الأسبوعية للنشر" (PDF).

خيارات مجانية موصى بها:
- Amiri: https://fonts.google.com/specimen/Amiri
- Noto Naskh Arabic: https://fonts.google.com/noto/specimen/Noto+Naskh+Arabic
- Cairo: https://fonts.google.com/specimen/Cairo

خطوات سريعة:
1. نزّل ملف "Regular" بصيغة .ttf من أحد الروابط أعلاه.
2. أعد تسميته إلى `arabic.ttf` وضعه في هذا المجلد.
3. أعد تشغيل الخادم.

لم يكن بالإمكان تضمين ملف الخط تلقائيًا من بيئة التطوير المستعملة لبناء هذا
المشروع بسبب قيود شبكية على تنزيل ملفات الخطوط من هناك؛ هذه خطوة تُنجَز مرة
واحدة فقط على جهازك العادي بوصول اعتيادي للإنترنت.
