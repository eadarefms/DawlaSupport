# البنية المعمارية — منصة الدعم التربوي عن بعد

## 1. نظرة عامة

```
┌─────────────────────────────────────────────────────────────────┐
│                         المستخدمون                                │
│   أستاذ | تلميذ | منسق إقليمي | رئيس مصلحة | مسؤول النظام          │
└───────────────────────────────┬─────────────────────────────────┘
                                 │  HTTPS
┌───────────────────────────────▼─────────────────────────────────┐
│                     Frontend (React + TypeScript)                │
│  Vite • Tailwind CSS (RTL) • React Router • React Query          │
│  Recharts (رسوم بيانية) • Lucide Icons                            │
└───────────────────────────────┬─────────────────────────────────┘
                                 │  REST/JSON + JWT (Bearer)
┌───────────────────────────────▼─────────────────────────────────┐
│                    Backend (Node.js + Express + TS)              │
│  ├─ Auth (JWT, bcrypt)                                            │
│  ├─ RBAC Middleware (ADMIN/REGIONAL_HEAD/COORDINATOR/TEACHER/     │
│  │                    STUDENT)                                    │
│  ├─ Modules: Users, Teachers, Students, Sessions, Schedule,      │
│  │           Enrollments, Meetings, Hours & Certificates,        │
│  │           Notifications, Reports (PDF/Excel), Settings        │
│  ├─ MeetingProvider abstraction (Teams | Meet | Jitsi | Manual)  │
│  ├─ Mailer abstraction (SMTP provider configurable via env)      │
│  └─ Cron Jobs (تذكير قبل 24 ساعة، إلخ.)                            │
└───────────────────────────────┬─────────────────────────────────┘
                                 │  Prisma ORM
┌───────────────────────────────▼─────────────────────────────────┐
│                  PostgreSQL (قاعدة البيانات العلائقية)             │
└───────────────────────────────────────────────────────────────────┘
```

## 2. اختيار التقنية (Stack)

| الطبقة | التقنية | السبب |
|---|---|---|
| Frontend | React + TypeScript + Vite | سريع، حديث، دعم ممتاز لـ TS |
| التنسيق | Tailwind CSS | يسهّل دعم RTL والتصميم المتجاوب |
| الحالة/البيانات | React Query + Context | تخزين مؤقت وتزامن بسيط مع الـ API |
| الرسوم البيانية | Recharts | مجاني، مرن، خفيف |
| Backend | Node.js + Express + TypeScript | بسيط، ناضج، سهل التوسع لاحقًا إلى NestJS |
| قاعدة البيانات | PostgreSQL | علائقية، مجانية، تمنع التكرار عبر القيود (constraints) |
| ORM | Prisma | Type-safe، Migrations واضحة، Seed سهل |
| المصادقة | JWT (access + refresh) + bcrypt | لا يحتاج بنية تحتية إضافية (لا Redis إجباري) |
| PDF | @react-pdf/renderer (خادم) | يدعم العربية RTL بشكل جيد مع خط عربي مضمّن |
| Excel | ExcelJS | مجاني، يدعم التنسيق والعناوين العربية |
| البريد | Nodemailer + مزود SMTP قابل للتغيير (Gmail App Password / Brevo / Mailtrap للتجربة) | لا يتطلب بطاقة بنكية |
| الاجتماعات | MeetingProvider interface: Manual (افتراضي) / Jitsi (رابط عشوائي بدون حساب) / Teams (لاحقًا عبر Graph API) | يمنع الاعتماد الإجباري على خدمة مدفوعة |
| الجدولة | node-cron | تذكيرات قبل 24 ساعة وقابلة للتوسع |

## 3. مبدأ العزل بين المديريات (Multi-tenancy منطقي)

كل سجل حساس (أستاذ، تلميذ، حصة) مرتبط بـ `provinceId`. الوسيط (middleware) الخاص بالصلاحيات يحقن فلترة `provinceId` تلقائيًا لأي مستخدم من نوع "منسق إقليمي"، بينما "رئيس المصلحة" و"المسؤول" يريان كل المديريات الثمانية.

## 4. مبدأ السنة الدراسية

كل الكيانات التشغيلية (Session، Enrollment، Schedule، الإحصائيات) تحمل `schoolYearId`. عند إنشاء سنة دراسية جديدة، لا تُحذف البيانات السابقة؛ فقط تتغير "السنة النشطة" في `SystemSettings`.

## 5. مراحل التنفيذ

- **المرحلة 1 (هذا التسليم):** هيكلة المشروع، قاعدة البيانات الكاملة (Prisma schema)، Authentication (تسجيل/دخول الأستاذ والتلميذ)، RBAC الأساسي، واجهة RTL أساسية (تسجيل الدخول، إنشاء حساب، هيكل Dashboard بـ Sidebar/Topbar)، بيانات تجريبية (Seed).
- **المرحلة 2:** نظام اقتراح الحصص + منع التعارض + استعمال الزمن (Calendar).
- **المرحلة 3:** تسجيل التلاميذ في الدروس + منع التكرار + لوائح المستفيدين.
- **المرحلة 4:** البريد الإلكتروني + Cron Jobs للتذكير + روابط الاجتماعات.
- **المرحلة 5:** الساعات والشهادات.
- **المرحلة 6:** لوحات القيادة (أستاذ/إقليمي/جهوي) + الرسوم البيانية.
- **المرحلة 7:** PDF الرسمي للبرمجة الأسبوعية + Import/Export Excel.
- **المرحلة 8:** إعدادات النظام (الشعار، السنة الدراسية، مزود البريد) + الإشعارات + الأمان النهائي (rate limiting, audit).
