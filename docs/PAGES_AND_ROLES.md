# الصلاحيات، الصفحات، وسير العمل

## الأدوار (Roles)
| الدور | الرمز البرمجي | النطاق |
|---|---|---|
| مسؤول النظام | `ADMIN` | كل شيء + الإعدادات |
| رئيس مصلحة التعلم عن بعد | `REGIONAL_HEAD` | كل المديريات الثمانية |
| منسق إقليمي | `PROVINCIAL_COORDINATOR` | مديريته فقط (`provinceId`) |
| أستاذ | `TEACHER` | بياناته وحصصه فقط |
| تلميذ | `STUDENT` | بياناته وتسجيلاته فقط |

## خريطة الصفحات حسب الدور

### الأستاذ
Dashboard → المشاركة في تقديم حصة → استعمال الزمن (الخاص بي / حسب المستوى) → التلاميذ المستفيدون → الساعات → الشهادات → الإشعارات → الإعدادات الشخصية

### التلميذ
Dashboard → اختيار المستوى/الشعبة → استعمال الزمن المتاح → الدروس المتاحة → دروسي → حصصي القادمة → الإشعارات

### المنسق الإقليمي
Dashboard (مديريته) → الأساتذة → التلاميذ → الحصص → استعمالات الزمن → الساعات → الشهادات → الإحصائيات → التصدير

### رئيس المصلحة / المسؤول
Dashboard الجهوي (مقارنة 8 مديريات) → كل الوحدات أعلاه على المستوى الجهوي → التقارير → إعدادات النظام (شعار، سنة دراسية، بريد)

## سير عمل الأستاذ (مختصر)
إنشاء حساب (رقم التأجير) → دخول → اقتراح حصة (مستوى→شعبة إن وُجدت→مادة→عنوان الدرس) → اختيار تاريخ (ابتداءً من الأسبوع المقبل) → معاينة استعمال الزمن لتفادي التعارض → التحقق الخادمي من التعارض → قبول/برمجة الحصة → توليد/إدخال رابط اللقاء → ظهور الحصة في استعمال الزمن → متابعة التسجيلات → استخراج اللوائح → احتساب الساعات تلقائيًا → استحقاق شهادة كل 10 ساعات.

## سير عمل التلميذ (مختصر)
إنشاء حساب (رمز مسار) → دخول → اختيار المستوى/الشعبة → تصفح استعمال الزمن والدروس المتاحة → اختيار درس → تعبئة معلومات التسجيل → تأكيد (يُمنع التسجيل المزدوج) → ظهور الدرس في "دروسي" → استقبال رابط اللقاء بالبريد قبل الحصة بـ24 ساعة → الدخول إلى القسم الافتراضي.

## سير عمل المنسق الإقليمي
دخول → Dashboard مفلترة تلقائيًا على مديريته (عبر `provinceId` في التوكن) → تتبع ومراقبة → تغيير حالة الحصص إذا سُمح له → تصدير بيانات مديريته فقط.

## سير عمل رئيس المصلحة
دخول → رؤية شاملة لكل المديريات → مقارنة، فلترة متقدمة (مديرية/مستوى/شعبة/مادة/فترة/أستاذ) → تقارير وتصدير شامل → لا فلترة تلقائية بالمديرية.
